Markdown sanitiser library not added because the renderer never injects HTML. `pip-audit`/`npm audit` not run (no network allow-list for advisories in the pod).

## Original problem statement
Production-grade Real Estate ERP "KKT" for an Indian builder (FARM stack). Phase 1: Foundation, Auth/RBAC, Master Data, Project→Block→Flat generation. Royal deep navy theme. Designed so Phase 2 (bookings/payments), Phase 3 (website/CMS) and Phase 4 (reports) slot in cleanly.

## Architecture
- **Backend** FastAPI (`/app/backend`), async motor, all routes under `/api`, OpenAPI at `/api/openapi.json`, docs `/api/docs`.
  - `server.py` app + lifespan (indexes, idempotent seed) + error envelope `{detail, code}` (+`errors[]` on 422)
  - `db.py` client + `ensure_indexes()` · `crypto.py` Fernet encrypt/decrypt/mask (ENCRYPTION_KEY) · `permissions.py` canonical registry + system role bundles
  - `deps.py` JWT decode, `get_current_user`, `require(permission)`, project-scope helpers
  - `utils.py` ApiError, StrictModel (extra=forbid), ListParams/paginate/search, `write_audit`
  - `routers/` auth, users, roles, master (factory-generated CRUD per master kind), projects, blocks, flats, settings, audit, dashboard
  - `services/flat_generation.py` numbering patterns, snapshots, price computation, generate/resnapshot
  - `seed.py` coherent demo data (runs if `users` empty; `python seed.py` manual)
- **Frontend** React 19 + shadcn + Tailwind (`/app/frontend/src`): `lib/api.js` axios w/ silent refresh rotation, `context/AuthContext.jsx` (can/canAny), `components/layout/AppShell.jsx` (navy collapsible sidebar, gold active indicator), `components/common/*` (DataTable, Combobox, StatusChip, FlatDrawer, FlatsTable), pages: Login, Dashboard, Projects, ProjectDetail (tabs), BlockDetail (inventory grid), Flats, master/* (generic + FlatType + Milestone forms), Users, Roles, AuditLog, Settings.
- **Env**: MONGO_URL, DB_NAME, JWT_SECRET, JWT_ALGORITHM, ACCESS_TOKEN_MINUTES(15), REFRESH_TOKEN_DAYS(7), ENCRYPTION_KEY; frontend REACT_APP_BACKEND_URL.

## Implemented (Phase 1.5 — 2026-10-23) "Foundation Power-Up"
**Backend**

- Pagination: offset (`page/page_size`) + cursor (`cursor/limit`) → `{items,total,page,page_size,next_cursor}`; `?format=csv` export on flats/projects/parking/master lists

- Mongo-backed rate limits (TTL index): login 10/min/IP, writes 120/min/user, `429 + Retry-After`. *Deviation: supervisor runs `uvicorn --workers 1 --reload` (reload is incompatible with workers; config not modified) — code is multi-worker safe.*
