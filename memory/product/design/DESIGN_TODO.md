## Owner's design rules (never break)
- Elegance first. Beautiful, detailed, never cluttered, never boring.
- Owner's screenshots (CRED, Jeelive, sitepe, Elite card, Elite photos) are **inspiration for structure only**. Their colours are NOT the target ("those card colours are not that good, not that elegant"). No pastel / metallic / gradient tile colours, no per-card tints except the 3 customer-card states.
- Colour only where it carries meaning: sapphire = action / progress · coral = due / overdue · mint = advance · champagne gold = rare premium moments. Everything else graphite / white / grey. No rainbow.
- One font: Figtree. Night Elite default, Day mode CRED-like white.
- Do not touch booking, payment, staging, plan, pricing, ledger, cancellation, numbering logic. Look only.
