## Housekeeping (Step 8 items 1–2)
- `routers/admin.py::_reseed` used `importlib.import_module("tools.migrate_phase_m").main()`. The logic moved to `services/stage_plan_migration.py` (routers → services → core). The router imports it statically. `tools/migrate_phase_m.py` is now a thin CLI wrapper, and `routers/masters_plus.py` imports `ensure_booking_stage` from the service.
- Stray file `backend/ritten by conftest on the fresh snapshot#` deleted. **How it was created** (reproduced): an ad-hoc `sed -i 's#…#STORY_LOGIC_FILE = "…"  # written by conftest on the fresh snapshot#' …` used `#` as the delimiter. The `#` of the inline comment closed the expression, and sed read the trailing `w` as the **write-to-file flag**, writing the matched line to a file named `ritten by conftest on the fresh snapshot#`. No script in the repo does this (grep is clean). Guard: `test_format_gate::test_no_stray_file_names` fails if any tracked file name has characters outside `[A-Za-z0-9_./@+-[]]`. Rule for agents: never use `#` as the sed delimiter when the replacement has a comment. Use the editor tools.
